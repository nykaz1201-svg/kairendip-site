# Kairendip コーポレートサイト

静的HTML1枚。GitHub Pages で無料公開できます。

## 公開手順（GitHub Pages / 無料）

1. GitHub で新規リポジトリを作成（例: `kairendip-site`、Public）
2. このフォルダの中身をそのまま push

```bash
cd kairendip-site
git init
git add .
git commit -m "Initial corporate site"
git branch -M main
git remote add origin https://github.com/<YOUR_ACCOUNT>/kairendip-site.git
git push -u origin main
```

3. リポジトリの **Settings → Pages** で
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`
4. 数十秒後 `https://<YOUR_ACCOUNT>.github.io/kairendip-site/` で公開

## 独自ドメインをあてる場合

メールが `@kairendip.com` なので、同じ `kairendip.com` をあてるのが自然です。

1. `CNAME` というファイルを作り、1行目にドメインだけ書く

```
kairendip.com
```

2. DNS 側に以下を設定
   - apex (`kairendip.com`) → A レコード 4件
     `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`
   - `www` → CNAME `<YOUR_ACCOUNT>.github.io`
   - ※ 既存の MX レコード（メール用）は消さないこと
3. Settings → Pages で `Enforce HTTPS` にチェック

ドメイン代以外は無料です。

### ⚠ 役職表記の確認

合同会社の登記上の代表者の役職は **「代表社員」** です。「代表取締役社長」は株式会社の役職なので、
サイト上は `代表社員　中村 幸子` としています。登記事項証明書と照合してください。

許可申請では登記事項証明書とサイト・申請書の表記が一致している必要があります。

## ⚠ 事業内容欄の運用

登記の目的（全10号）のうち、サイトには **1・2・5・6・7・8号** を掲載しています。
会社概要に登記の全目的を載せる義務はないので、これで問題ありません。

省略している号：3（EC）・4（コンピュータシステム保守）・10（附帯）。
9（有料職業紹介事業）は下記の理由で許可取得まで非掲載。

**9号「有料職業紹介事業」は、許可が下りるまで絶対にサイトへ追加しないこと。**
登記の目的に入っていること自体は許可申請に必要な正しい状態ですが、
サイトに書くと「許可前に事業を行っている」と誤認される記載になります。

許可取得後は、事業内容欄に9号を追加し、あわせて許可番号（`13-ユ-3xxxxx`）・
手数料表・取扱職種の範囲・個人情報の取扱いをフッターまたは専用ページに掲載します。

## ⚠ 編集時の禁止語（職業安定法・許可申請対応）

有料職業紹介事業の許可が下りるまで、このサイトに以下の語を**入れないこと**。
東京労働局の「ホームページチェックリスト」で確認される項目です。

```
人材紹介 / 転職 / 求人 / 求職 / キャリア支援 / キャリア相談
マッチング / スカウト / ヘッドハンティング / 候補者 / 採用代行 / RPO
面接代行 / 委託募集 / 人材仲介 / 派遣 / 紹介手数料 / 許可番号
```

チェック用：

```bash
grep -nE "人材|紹介|求人|求職|転職|マッチング|スカウト|候補者|採用代行|面接代行|委託募集|派遣|キャリア|ヘッドハンティング|許可番号" index.html
```

何もヒットしなければOK。
